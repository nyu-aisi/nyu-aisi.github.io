A Cryptographic Perspective on Fingerprinting Machine Learning Model Weights

Kameron Shahabi

Monday, November 30, 2026 · 1–2 PM (New York time)
Warren Weaver Hall, Room 1314

The talk will discuss a cryptographic framework for fingerprinting machine learning model weights so that models can be attributed to their providers. The work considers users who modify a base model after receiving it, for example through fine-tuning.

Read the paper, joint work with Huijia Lin.
